# 2026-11-05-007: First CI run on GitHub, format fix

## What was asked
The first push to GitHub (run 42018619541) failed 6 of 8 CI checks. Fix CI and commit.

## What we found
- All 6 failures (Dart and Rust, on all three OSes) were the **format check** step, not tests or builds.
  - `cargo fmt --check`: one long `assert_eq!` in `extension/src/install.rs`.
  - `dart format --set-exit-if-changed`: `cli/test/unit/control/session_store_test.dart` and `cli/test/unit/schema_test.dart`.
- Integration (flutter-tester, Linux) and Version consistency passed.

## Lesson
Run `dart pub get` **before** `dart format`. Without `.dart_tool/package_config.json`, the formatter can't
resolve the package language version or `analysis_options.yaml`, so it uses the wrong style and rewrites
about 30 files. Running `dart format` again after `pub get` puts them back.
